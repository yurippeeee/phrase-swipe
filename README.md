# Phrase Swipe

聞いて、選んで、繋げる。スマホ向けの「選ぶ」作曲Webアプリです。

ビルド不要の静的サイト（`index.html` + `js/` + `css/`）。音源は CDN 版 [Tone.js](https://tonejs.github.io/) を使います。

## 使い方

1. **設定**：キー / スケール / BPM / フレーズの長さ（ランダム・1小節・2小節）/ コード進行（度数。例 `I-V-vi-IV`、`ii-V7-Imaj7`、`bVII` も可）
2. **選ぶ**：カードが表示されるとループ再生されます。右スワイプ（♥）でキープ、左スワイプ（✕）でボツ。カードをタップで再生/停止
3. **くり返し候補**：キープすると、次の候補の先頭にそのフレーズの「くり返し」（次のコードに合わせて音階上でずらしたもの）、「くり返し・語尾変え」、1つ前のフレーズへの戻り（A B A）が並びます
4. **これに近いの**：表示中のフレーズからリズム違い・音程違い・一部変更の派生を5つ作り、次の候補に差し込みます
5. **文脈試聴**：ONにすると、直前にキープしたフレーズ → 候補 の順で続けて再生します
6. **棚**：キープしたフレーズを ≡ のドラッグで並べ替え、⧉ で直後に複製（くり返し）、通し再生。行をタップでその1フレーズだけ再生。「伴奏」でコード進行をパッドで鳴らします
7. **MIDI書き出し**：Melody / Chords の2トラックで `.mid` を保存します

状態（設定・棚）は localStorage に保存されます。

## 生成ルール（概要）

- 1拍・2拍単位のリズムセルを密度に応じて選択。同じセルで1小節を刻むことも、2小節目で1小節目の動機を反復することもある
- 半小節ごとに音程パターンを選ぶ：1音ずつ選ぶ / 同音連打 / 2音交互 / 音階を一方向に / 前の半小節をなぞる。フレーズごとに得意パターンを1つ決めて重みを上げる
- 反復した動機は音程も写す（そのまま、または音階上でずらしたゼクエンツ）
- 強拍（1・3拍目）、長い音、最後の音はコードトーン（パターンの音がコードに合わなければ最寄りのコードトーンへ寄せる）
- 1音ずつ選ぶときは順次進行を優先し、跳躍の後は反対方向へ戻す。増4度は抑制
- 語尾を1〜2拍休む（息継ぎ）、頭を休符から始めるなどで実際の長さもばらつかせる
- 小節ごとにコード進行の位置を割り当て、キープするたびに次の位置へ進む

## 公開（GitHub Pages）

Settings → Pages → Branch を選んで保存するだけで動きます。ローカルでは `npx http-server .` などで配信してください（ES Modules のため `file://` 直開きは不可）。

iOS はマナーモード時に音が出ない場合があります（Safari 16.4+ は自動で回避を試みます）。
