# Phrase Swipe

聞いて、選んで、繋げる。スマホ向けの「選ぶ」作曲Webアプリです。

ビルド不要の静的サイト（`index.html` + `js/` + `css/`）。音源は CDN 版 [Tone.js](https://tonejs.github.io/) を使います。

## 使い方

1. **設定**：キー / スケール / BPM / フレーズの長さ（ランダム・1小節・2小節）/ コード進行。先頭のコードを選ぶと、そこから続く定番の4コード進行が一覧で出ます。3コードや5コード以上はカスタム欄に入力（度数。例 `I-V-vi-IV`、`ii-V7-Imaj7`、`bVII` も可）
2. **選ぶ**：カードが表示されるとループ再生されます。右スワイプ（♥）でキープ、左スワイプ（✕）でボツ。カードをタップで再生/停止
3. **くり返し**：キープすると、カードの下に直前のフレーズと連続回数（×n）が出ます。
   - 「くり返す」：全く同じフレーズ（コードも同じ）を棚に足す
   - 「語尾違い」：直前のフレーズの語尾だけ変えた候補を5つ並べる。スワイプで選ぶ（例：3回くり返して4回目で語尾を変える）
   - くり返しの後の新しい候補は、元のフレーズの続きのコードから始まります
4. **これに近いの**：表示中のフレーズからリズム違い・音程違い・一部変更の派生を5つ作り、次の候補に差し込みます
5. **伴奏を選ぶ**：選ぶ画面上部の「伴奏」に切り替えると、伴奏パターンをカードで選べます（メロディと一緒に再生）。パッド・刻み・ベース＋和音・アルペジオ・和音＋アルペジオ・分散・ベースラインがあり、ときどき単音のフィルが入ります。決めた伴奏は対象のフレーズと、これからキープするフレーズに付きます。棚の ♫ でフレーズごとに選び直し、「棚全体に適用」で一括変更
6. **文脈試聴**：ONにすると、直前にキープしたフレーズ → 候補 の順で続けて再生します
7. **棚**：キープしたフレーズを ≡ のドラッグで並べ替え、⧉ で直後に同じフレーズを複製、通し再生。行をタップでその1フレーズだけ再生。「伴奏」で選んだ伴奏を一緒に鳴らします
8. **MIDI書き出し**：Melody / Accomp / Bass の3トラックで `.mid` を保存します

状態（設定・棚）は localStorage に保存されます。伴奏が大きすぎ・小さすぎるときは設定の「伴奏の音量」で調整できます（その場で反映）。

## 生成ルール（概要）

- 1拍・2拍単位のリズムセルを密度に応じて選択。同じセルで1小節を刻むことも、2小節目で1小節目の動機を反復することもある
- 半小節ごとに音程パターンを選ぶ：1音ずつ選ぶ / 同音連打 / 2音交互 / 音階を一方向に / 前の半小節をなぞる。フレーズごとに得意パターンを1つ決めて重みを上げる
- 反復した動機は音程も写す（そのまま、または音階上でずらしたゼクエンツ）
- 強拍（1・3拍目）、長い音、最後の音はコードトーン（パターンの音がコードに合わなければ最寄りのコードトーンへ寄せる）
- 1音ずつ選ぶときは順次進行を優先し、跳躍の後は反対方向へ戻す。増4度は抑制
- 語尾を1〜2拍休む（息継ぎ）、頭を休符から始めるなどで実際の長さもばらつかせる
- 小節ごとにコード進行の位置を割り当て、キープするたびに次の位置へ進む

## 公開（GitHub Pages）

Settings → Pages → Branch を選んで保存するだけで動きます。ローカルでは `npx http-server .` などで配信してください（ES Modules のため `file://` 直開きは不可）。

更新時は `index.html` の `app-version` と各 `?v=` を同じ値に上げてください。GitHub Pages のキャッシュで古いJSが混ざるのを防ぎます（設定画面の下に表示されるバージョンで確認できます）。

iOS はマナーモード時に音が出ない場合があります（Safari 16.4+ は自動で回避を試みます）。
