# Phrase Swipe

聞いて、選んで、繋げる。スマホ向けの「選ぶ」作曲Webアプリです。

ビルド不要の静的サイト（`index.html` + `js/` + `css/`）。音源は CDN 版 [Tone.js](https://tonejs.github.io/) を使います。

## 使い方

1. **設定**：キー / スケール / BPM / フレーズの長さ（ランダム・1小節・2小節）/ コード進行。先頭のコードを選ぶと、そこから続く定番の4コード進行が一覧で出ます。3コードや5コード以上はカスタム欄に入力（度数。例 `I-V-vi-IV`、`ii-V7-Imaj7`、`bVII` も可）
2. **選ぶ**：カードが表示されるとループ再生されます。右スワイプ（♥）でキープ、左スワイプ（✕）でボツ。カードをタップで再生/停止
   - コードは曲の中の位置で決まります。棚の先頭から小節を数えてコード進行を順に当てはめるので、くり返したフレーズもメロディは同じまま、コードは次へ進みます。並べ替え・削除・進行の変更をすると棚全体のコードが付け直されます（キー・スケールを変えたらメロディも移調）
   - カードの上の帯はコード進行で、今のカードが担当するコードが光ります。帯のコードをタップすると、そのコードから作り直します
   - 帯の右端の「進行を変える」で、曲の途中からコード進行を切り替えられます（Aメロ→サビのような区切り）。次のフレーズから新しい進行の1つ目のコードで始まります。進行がちょうど1周したところではボタンが光ります。棚では各フレーズの「進行 ▾」から、そのフレーズ以降の進行を切り替えられます。区切りには「▶ 進行」の印が付き、タップで変更・削除できます（メロディはそのまま、コードだけ付け直し）。設定の進行は曲の最初の区間の進行です
3. **くり返し**：キープすると、カードの下に直前のフレーズと連続回数（×n）が出ます。
   - 「くり返す」：全く同じメロディを棚に足す（コードは進行に沿って次へ）
   - 「語尾違い」：直前のフレーズの語尾だけ変えた候補を5つ並べる。語尾は次のコードに合わせて作る。スワイプで選ぶ（例：3回くり返して4回目で語尾を変える）
4. **これに近いの**：表示中のフレーズからリズム違い・音程違い・一部変更の派生を5つ作り、次の候補に差し込みます
5. **伴奏を選ぶ**：選ぶ画面上部の「伴奏」に切り替えると、伴奏パターンをカードで選べます（メロディと一緒に再生）。パッド・刻み・ベース＋和音・アルペジオ・細かいアルペジオ・カッティング・和音＋アルペジオ・分散・ベースラインがあり、リズムはメロディと同じく1拍ごとに16分・8分・4分・休符を混ぜて作ります。♥した伴奏は**伴奏の棚**に貯まります（棚画面の「伴奏」タブで試聴・「全体」で曲全体に使う・削除）。各フレーズの伴奏は棚の ♫ から伴奏の棚の中で選び、気に入るのがなければそこからスワイプで探せます。伴奏を付けていないフレーズは標準（8分の刻み）で鳴ります。伴奏モードの「合いの手」スライダー（0〜100%）で、伴奏がメロディの間（休み・伸ばし）に短いフレーズを入れ、メロディの出だしとぶつかる音を控える度合いを調整できます。動かすと今のカードにすぐ反映され、次の候補もその強さの前後で作ります。合いの手は再生のたびに各フレーズのメロディに合わせるので、同じ伴奏でもフレーズごとにその間を埋めます
6. **文脈試聴**：ONにすると、直前にキープしたフレーズ → 候補 の順で続けて再生します
7. **棚の近いのを探す**：棚のフレーズの「近いの」で、そのフレーズに近い候補をスワイプで探せます。メロディ違い（リズム・音程・一部・語尾）と、コード違い（その小節のコードを代理コードやセブンスに差し替え、メロディの強拍を合わせる）が混ざって出ます。♥で棚のそのフレーズと差し替え。伴奏の棚の「近いの」では、似た伴奏を探せます
8. **棚**：キープしたフレーズを ≡ のドラッグで並べ替え、⧉ で直後に同じフレーズを複製、通し再生。行をタップでその1フレーズだけ再生。「メロディ」「伴奏」のON/OFFで、伴奏だけ・メロディだけでも聴けます
9. **MIDI書き出し**：Melody / Accomp / Bass の3トラックで `.mid` を保存します

状態（設定・棚）は localStorage に保存されます。伴奏が大きすぎ・小さすぎるときは設定の「伴奏の音量」で調整できます（その場で反映）。

## 生成ルール（概要）

- 1拍・2拍単位のリズムセルを密度に応じて選択。同じセルで1小節を刻むことも、2小節目で1小節目の動機を反復することもある
- 半小節ごとに音程パターンを選ぶ：1音ずつ選ぶ / 同音連打 / 2音交互 / 音階を一方向に / 前の半小節をなぞる。フレーズごとに得意パターンを1つ決めて重みを上げる
- 反復した動機は音程も写す（そのまま、または音階上でずらしたゼクエンツ）
- 強拍（1・3拍目）、長い音、最後の音はコードトーン（パターンの音がコードに合わなければ最寄りのコードトーンへ寄せる）
- 1音ずつ選ぶときは順次進行を優先し、跳躍の後は反対方向へ戻す。増4度は抑制
- 語尾を1〜2拍休む（息継ぎ）、頭を休符から始めるなどで実際の長さもばらつかせる
- 小節ごとにコード進行の位置を割り当て、キープするたびに次の位置へ進む

## 公開（GitHub Pages）

Settings → Pages → Branch を選んで保存するだけで動きます。ローカルでは `npx http-server .` などで配信してください（ES Modules のため `file://` 直開きは不可）。

更新時は `index.html` の `app-version` と各 `?v=` を同じ値に上げてください。GitHub Pages のキャッシュで古いJSが混ざるのを防ぎます（設定画面の下に表示されるバージョンで確認できます）。

iOS はマナーモード時に音が出ない場合があります（Safari 16.4+ は自動で回避を試みます）。
